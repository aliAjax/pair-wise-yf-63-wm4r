# 跨国临床试验随机分组和揭盲控制台

源提示词摘要：研究中心按分层因素生成随机分组；发号采用**先领后确认**两阶段——协调员按分层区组领号预占，处理期间他人领不到，超时未确认号码放回区组再发；确认时号码已被收回/转号或两人同时提交只让一边成功；名额不足按中央容量排队；写盘失败按预占编号幂等重试，号码与名额不重复占。药品管理员只见发药信息，研究角色正常情况下不可见治疗组；重复受试者和编号冲突被阻止；紧急揭盲需填写原因并形成不可删除审计记录，断网提交进入待处理队列。

## 发号模型（先领后确认）

1. **领号（claim）**：按 `研究中心 × 年龄分层` 从平衡区组（每块 A/B 等量，块内洗牌）取第一个可发号码，生成预占编号 `holdNo` 并预占 45 秒（演示值，生产常量 `HOLD_TTL_MS` 为 30 分钟）。预占期间：
   - 同一号码他人领不到（有效预占集合排除该号）；
   - 名额同时被预占口径占用（总量 = 已确认 + 有效预占 + 剩余）。
2. **确认（confirm）**：带预占版本号做 CAS：
   - 号码已被超时收回或转给排队者 → `gone`；
   - 两个协调员用同一预占同时提交 → 版本/账本只认第一边，另一边 `conflict`，只产生一条入组；
   - 成功后号码出池、计入已占用名额，治疗组作为受控字段落库。
3. **超时回收**：秒级扫描，过期预占解除，号码天然回到可发集合；该层若有排队者，队首自动补位拿到预占。
4. **临时退出**：协调员主动取消，号码立即放回区组并触发排队补位，不产生入组记录。
5. **中央容量排队**：某层 `已确认 + 有效预占` 达到容量上限时，领号请求转为排队（返回队位），不占号码；有名额释放（取消/超时）后按 FIFO 补位。
6. **写盘失败重试（幂等）**：账本按 `holdNo + phase` 记忆 claim/confirm 结果。写盘失败后用同一预占编号原样重试：本人重试回放原结果（`replayed`），不重复占号、不重复占名额；他人拿同号重复提交判 `conflict`。界面「模拟下次写盘失败」开关可演示。

## 角色边界

- **研究者/协调员**：可见受试者与号码；治疗组默认隐藏，紧急揭盲（需填原因，仅追加审计）后可见。
- **药品管理员**：发药台账中**不渲染治疗组列数据**（显示为隐藏占位），只能看到/使用发药编号 `KIT-xxxx` 进行出库登记；发药审计文本不含治疗组。
- **监察员**：仅在已揭盲记录上可见治疗组。

## 其他流程

- 防重复：相同身份标识或受试者编号在「已确认 / 预占中 / 排队中」任一状态都会拒绝。
- 离线队列：模拟离线时领号进入待提交队列（不占池），联网后由授权人员执行「领号 + 确认」入库。
- 安全审计：所有领号、放回、补位、确认、冲突、发药、揭盲动作只追加，不可删除或改写。
